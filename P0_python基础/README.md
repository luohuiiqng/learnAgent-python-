**时间**：第 1-3 周（2026-11-09 至 11-29），每周 15 到 20 小时

## 每课的学法

1. 读 README，每读完一节就运行对应的示例脚本，对照输出读注释。
2. 输出和预期不一样时，先改代码验证自己的猜想，再往下读。
3. 做 `练习.py`，运行 `python 练习.py`，直到全部 ✅。
4. 告诉教练“第 N 课学完了”，开始评估（规则见 `docs/评估规范.md`）。

## 环境注意事项

- 一律用 `python`（conda），不要用 `python3`。
- 本机有系统代理 `127.0.0.1:8080`。用 httpx、requests 访问本机服务时会返回 503，需要 `NO_PROXY=localhost,127.0.0.1` 或 `trust_env=False`。curl 和数据库驱动不受影响。
- 本机 6379 端口被 Homebrew 的 Redis 占用，9000 端口被 MinIO 占用。第 7 课的 README 写了换端口的方法。
